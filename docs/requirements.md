# 要件定義書

## 1. プロジェクト概要

### 目的
日常の買い物レシートを写真で記録・管理し、支出の可視化と商品価格の比較を通じて、より賢い購買行動を支援する。

### 対象ユーザー
個人の家計管理を行う一般ユーザー

---

## 2. 機能要件

### 2.1 レシート登録

| # | 要件 | 優先度 |
|---|---|---|
| F-01 | レシートの画像（JPEG/PNG）をアップロードできる | 高 |
| F-02 | アップロードした画像をAI（Claude API）で解析し、店舗名・日付・合計金額・商品リストを自動抽出できる | 高 |
| F-03 | AIを使わず、店舗名・日付・合計金額・商品リストを手動入力で登録できる | 高 |
| F-04 | ANTHROPIC_API_KEYが未設定の場合、AI解析をスキップして画像のみ保存できる | 中 |

### 2.2 ダッシュボード

| # | 要件 | 優先度 |
|---|---|---|
| F-05 | 今月の合計支出を表示できる | 高 |
| F-06 | 全期間の合計レシート数・総支出を表示できる | 高 |
| F-07 | 最多利用店舗を表示できる | 中 |
| F-08 | 月別支出の棒グラフを表示できる | 高 |
| F-09 | 店舗別支出割合のドーナツグラフを表示できる | 高 |
| F-10 | 最近登録したレシート5件を一覧表示できる | 中 |

### 2.3 レシート一覧

| # | 要件 | 優先度 |
|---|---|---|
| F-11 | 登録済みレシートを新着順で一覧表示できる | 高 |
| F-12 | レシートの詳細（店舗・日付・合計・商品リスト）を確認できる | 高 |

### 2.4 価格比較

| # | 要件 | 優先度 |
|---|---|---|
| F-13 | 商品名（部分一致）で検索できる | 高 |
| F-14 | 店舗ごとの平均価格・最安値・最高値・購入回数・最終購入日を表示できる | 高 |
| F-15 | 平均価格が最安の店舗をハイライト表示できる | 中 |

### 2.5 その他

| # | 要件 | 優先度 |
|---|---|---|
| F-16 | 動作確認用のサンプルデータ（100件）を一括投入できる | 低 |

---

## 3. 非機能要件

| # | 要件 |
|---|---|
| NF-01 | ビルドステップなしで動作する（純粋なHTML/CSS/JS） |
| NF-02 | APIキーなしでも基本機能（手動登録・一覧・価格比較）が使える |
| NF-03 | ローカル環境で単一コマンドで起動できる |
| NF-04 | データはローカルのSQLiteファイルに保存される（外部DBサーバー不要） |
| NF-05 | レスポンシブデザイン（スマートフォン対応） |

---

## 4. 対象外（スコープ外）

- ユーザー認証・マルチユーザー対応
- クラウドへのデプロイ・データ同期
- レシート画像の編集・削除
- 予算設定・アラート機能
- CSV/PDFエクスポート
